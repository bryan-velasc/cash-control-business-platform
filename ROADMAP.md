# Roadmap del Proyecto

## Fase 0: Organización y documentación

- Crear repositorio base.
- Crear estructura de carpetas.
- Crear documentación inicial.
- Crear README.
- Crear SECURITY.
- Crear CHANGELOG.
- Crear ROADMAP.

## Fase 1: Página web

- Rediseñar interfaz visual.
- Mejorar colores.
- Crear catálogo más profesional.
- Agregar vista responsive.
- Agregar métodos de pago visibles.
- Agregar botón de WhatsApp.

## Fase 2: Productos y stock

- Crear modelo de productos.
- Crear endpoints de productos.
- Mostrar productos dinámicos en la web.
- Administrar stock desde Cash Control.

## Fase 3: Clientes y fiados

- Crear módulo de clientes.
- Registrar deudas.
- Registrar pagos.
- Crear vista privada para clientes.
- Ocultar información pagada de la vista activa.

## Fase 4: Pagos

- Registrar pagos en efectivo.
- Registrar pagos por transferencia.
- Integrar pagos con tarjeta.
- Confirmar pagos desde backend.

## Fase 5: SMS y recordatorios

- Enviar recordatorio los viernes.
- Verificar si el cliente pagó.
- Marcar deuda como pagada, pendiente o atrasada.

## Fase 6: Fidelidad

- Agregar puntos por compra.
- Crear recompensas.
- Mostrar puntos al cliente.

## Fase 7: Reportes

- Ganancias estimadas.
- Pérdidas.
- Productos más vendidos.
- Reporte predictivo de ventas.
