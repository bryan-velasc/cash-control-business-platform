# Cash Control Business Platform

Proyecto desarrollado por Bryan Micheell Velasco Cruz.

## Descripción

Cash Control Business Platform es una plataforma diseñada para administrar un negocio de venta de dulces mediante una página web pública, una aplicación móvil administrativa, un backend centralizado y una base de datos en la nube.

El objetivo principal es conectar una página web alojada en Netlify con la aplicación Cash Control para administrar productos, stock, clientes, fiados, pagos, proveedores, ganancias, pérdidas, fidelidad y reportes predictivos.

## Objetivo del proyecto

Crear una solución escalable que permita:

- Mostrar productos y precios en una página web.
- Consultar información limitada del cliente.
- Administrar stock desde Cash Control.
- Controlar clientes y fiados.
- Registrar pagos en efectivo, transferencia y tarjeta.
- Enviar recordatorios de pago.
- Crear programa de fidelidad.
- Generar reportes de ganancias y pérdidas.
- Documentar el desarrollo con enfoque profesional y de ciberseguridad.
