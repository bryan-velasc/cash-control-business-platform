# Resumen Ejecutivo

## Nombre del proyecto

Cash Control Business Platform

## Autor

Bryan Micheell Velasco Cruz

## Descripción general

Cash Control Business Platform es un proyecto que busca integrar una página web de venta de dulces con la aplicación Cash Control, permitiendo administrar productos, clientes, fiados, pagos, inventario, proveedores, ganancias, pérdidas y reportes predictivos.

## Situación actual

Actualmente existe una página web alojada en Netlify desarrollada con HTML. La página muestra imágenes y precios de productos, pero no permite registrar pedidos, controlar stock, administrar clientes ni conectarse con Cash Control.

Cash Control conserva su estructura original basada en aplicación móvil, backend y base de datos. El objetivo es ampliar sus funciones para que también pueda servir como panel administrativo del negocio.

## Problema

El negocio necesita una forma ordenada y escalable de administrar ventas, stock, clientes, pagos y reportes. La página web actual no tiene conexión con base de datos ni mecanismos de administración.

## Solución propuesta

Crear una arquitectura donde la página web funcione como catálogo público y vista limitada para clientes, mientras Cash Control funcione como panel administrativo. El backend será el encargado de conectar ambos sistemas con MongoDB Atlas.

## Enfoque profesional

El proyecto será documentado desde cero para servir como evidencia técnica en portafolio profesional, especialmente orientado a áreas de desarrollo seguro y ciberseguridad.

## Objetivos principales

- Mejorar la página web de venta de dulces.
- Conectar la página con Cash Control.
- Administrar stock desde la app.
- Controlar clientes y fiados.
- Registrar pagos.
- Crear recordatorios.
- Implementar fidelidad.
- Generar reportes.
- Documentar errores, soluciones y decisiones técnicas.
